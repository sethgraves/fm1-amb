# fm1-base, copied in

This folder is [fm1-base](https://github.com/charlesvestal/fm1-base) by Charles Vestal at commit
`3ae2a65ddd02e15bf9ce925b5a7136d5d207ee25`, with [felucca-bsp](https://github.com/hugelton/felucca-bsp) (from Felucca by Leo Kuroshita,
Hügelton Instruments) in `bsp/` at commit `f878800967e66e721dfbc9a4f5fe1835772ae8fc`, both MPL-2.0, copied unchanged.

They were git submodules; they are copied in so that DREAM's complete source is in this repository at every
release tag, as The Firmware Hub asks. To update: replace this folder with a newer fm1-base (and its `bsp/`),
note the commits here, build, and run the tests.
